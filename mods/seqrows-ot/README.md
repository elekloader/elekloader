# seqrows (Octatrack)

Rows mods add to PROJECT > CONTROL > SEQUENCER, as `ot_seq_label`, `ot_seq_get` and `ot_seq_set`
(docs/ADAPTING.md, "SEQUENCER rows on the Octatrack"). A companion of core-ot rather than core: octabam's
SCALE QUANTIZER (v1.0, in the shop) patches the same seven places to add its own rows, so the two refuse
each other and core keeps linking with QUANTIZER. `tests/fixtures/octatrack-seqrows` adds a row.
