# Shared machine SDK (alpha)

The [SDK guide](../../../../docs/SDK.md) describes supported devices, UI
features, the audio contract, building and current limitations.

[sdk_alpha_machine.h](sdk_alpha_machine.h) is the reference for exact C
types and fields. The API is private; the Digitakt mk1 and Digitone mk1
render SDK machines, and the Digitone II's render backend is not yet
implemented.
